# Privacy

Code Crew is a prompt-only, open-source skill package. The package itself does not collect, store, or transmit personal data, and it does not include analytics, network integrations, background services, or executable hooks.

The agent host running Code Crew may read repository content, call tools, or send prompts to its model provider according to the user's request and that host's configuration. Those operations are controlled by the host and are subject to its privacy policy, permissions, and data-retention settings.

Questions or suspected privacy issues can be reported through the repository's [GitHub issues](https://github.com/gmentat/code-crew/issues).
